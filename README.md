# Buy Price Assistant GIMI

تطبيق أندرويد عربي مرجعي لأسعار شراء الأصناف وبيعها، مصمم للعمل دون إنترنت باستخدام قاعدة بيانات SQLite محلية.

## الوظائف الموجودة في الإصدار الأول

- البحث الجزئي باسم الصنف أو الكود أو التصنيف، مع معالجة بعض اختلافات كتابة الحروف العربية والحركات.
- إضافة الأصناف وتعديل بياناتها وإضافتها إلى المفضلة.
- تسجيل كل عملية شراء أو بيع بتاريخها وسعر الوحدة والكمية.
- الاحتفاظ بسجل العمليات التاريخي؛ تعديل بيانات الصنف لا يغيّر الأسعار السابقة.
- عرض أحدث أسعار الشراء والبيع وتواريخها في نتائج البحث.
- عرض التاريخ الكامل للشراء والبيع، واسم المورد/العميل ورقم فاتورة الشراء والملاحظات.
- أرشفة الصنف دون حذف سجلاته التاريخية.
- إدخال أرقام عربية أو إنجليزية في حقول السعر والكمية.
- اختبارات وحدات واختبارات لقاعدة SQLite في بيئة CI.

## ملاحظات بيانات مهمة

- الأسعار المسجلة هي أسعار وحدة الصنف وليست إجمالي الفاتورة.
- فرق آخر سعر بيع عن آخر سعر شراء ليس صافي ربح محاسبيًا؛ لا يشمل النقل أو المصاريف أو الخصومات أو الضرائب.
- قاعدة البيانات محلية على الهاتف في هذا الإصدار. إزالة التطبيق أو فقدان بياناته قد يؤدي إلى فقدان السجلات؛ احتفظ بنسخ احتياطية مستقلة. ميزة النسخ الاحتياطي والاستعادة ليست مفعلة في هذا الإصدار الأول.
- هذا مشروع تجريبي أولي مخصص للتحقق من سير العمل والوظائف الأساسية قبل اعتماده للاستخدام التجاري اليومي.

## التقنية

- Flutter / Dart
- SQLite عبر `sqflite`
- اختبارات SQLite محلية عبر `sqflite_common_ffi`
- GitHub Actions لتحليل الكود وتشغيل الاختبارات وبناء APK

## بناء APK على GitHub

1. أنشئ مستودعًا فارغًا بالاسم `Buy-price-assistant-gimi`.
2. ارفع كل محتويات هذا المجلد إلى الفرع `main`.
3. افتح تبويب **Actions** في GitHub وانتظر سير العمل **Android CI** حتى ينتهي بحالة خضراء.
4. افتح تشغيل سير العمل الناجح، ثم نزّل artifact باسم يبدأ بـ `buy-price-assistant-gimi-apk-`.
5. فك ضغط artifact وثبّت `app-release.apk` على هاتف Android. هذا APK للتجربة، وليس إعداد توقيع إنتاج/متجر Play.
6. نزّل كذلك artifact باسم يبدأ بـ `resolved-pubspec-lock-`، واستخرج منه `pubspec.lock` وضعه في جذر المشروع ثم ارفعه إلى المستودع. بهذه الخطوة تُثبَّت الإصدارات العابرة التي نجح معها البناء، ويستخدم CI خيار `--enforce-lockfile` بعد وجود الملف.

يُولّد مجلد `android/` داخل بيئة البناء من إصدار Flutter stable المستخدم في تشغيل CI. لا يُسمح للبرنامج النصي باستبدال مجلد `android/` موجود مسبقًا.

## التشغيل محليًا عند توفر Flutter SDK

```bash
flutter pub get
dart format lib test
flutter analyze --fatal-infos
flutter test
python3 tool/prepare_android.py
flutter pub get
flutter build apk --release
```

## الحدود المعروفة للإصدار الأول

- لا يوجد حتى الآن مزامنة سحابية أو تعدد مستخدمين.
- لا يوجد استيراد/تصدير ملفات Excel أو CSV أو نسخ احتياطي واستعادة من داخل الواجهة؛ لا تعتمد على هذا الإصدار كمستودع بيانات وحيد قبل إضافة واختبار النسخ الاحتياطي والاستعادة.
- لا يوجد ماسح باركود بالكاميرا رغم إمكانية البحث بكتابة الكود يدويًا.
- سجل الأسعار يُظهر العملة ثابتة حاليًا على `ر.ي` (ريال يمني).

هذه الوظائف لا ينبغي اعتبارها منجزة إلى أن تضاف وتُختبر في إصدار لاحق.
