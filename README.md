# Buy Price Assistant HJI

تطبيق Android مبني بـ Flutter لإدارة مرجع أسعار الأصناف وسجل عمليات الشراء والبيع، مع قاعدة بيانات SQLite محلية والعمل دون اتصال بالإنترنت.

## الإصدار

- اسم التطبيق: **Buy Price Assistant HJI**
- رقم الإصدار: **1.4.0+6**
- الفرع التطويري لهذه الحزمة: `feature/hji-professional-upgrade`

## الوظائف

- البحث في أسماء الأصناف والأكواد والتصنيفات والعلامات التجارية والملاحظات والموردين والعملاء وسجلات الشراء والبيع.
- توحيد الأرقام العربية والهندية والفارسية والإنجليزية في البحث وإدخال الأرقام.
- البحث عن الأصناف حتى عند اختلاف ترتيب كلمات الاسم، ومطابقة الاستيراد وفق الكلمات ووحدة القياس.
- تصفية القائمة حسب التصنيف والعلامة التجارية والمورد.
- إضافة الأصناف وتعديلها وأرشفتها والمفضلة، مع الاحتفاظ بسجل الأسعار التاريخي.
- تسجيل عمليات الشراء والبيع بالعملة والتاريخ والكمية والمورد/العميل والملاحظات.
- استيراد XLSX وCSV UTF-8 مع معاينة والتحقق قبل الكتابة، وتصدير البيانات وسجلات الأسعار.
- نسخ احتياطي واستعادة JSON مستقلان عن استيراد وتصدير الجداول.
- واجهة عربية/إنجليزية، ومظهر فاتح/داكن، وقائمة تنقل جانبية مدمجة.
- أيقونة تطبيق مخصصة برمز فاتورة وعملة تُنشأ أثناء تجهيز ملفات Android.

## سلامة البيانات

- لا تُحوّل العملات التاريخية تلقائيًا عند تغيير العملة الافتراضية.
- لا يُفترض أن فرق آخر سعر بيع وآخر سعر شراء هو صافي الربح.
- لا تحذف سجلات الأسعار عند تعديل بيانات الصنف أو أرشفته.
- يُحافظ على اسم ملف قاعدة البيانات الحالي لتجنب فقدان بيانات التثبيتات السابقة.
- خذ نسخة احتياطية JSON قبل تثبيت أي إصدار تجريبي جديد، واحتفظ بها خارج الهاتف.

## البناء والتحقق

يستخدم GitHub Actions لتحليل Dart، وتشغيل اختبارات الوحدة وقاعدة البيانات والاستيراد والتصدير، ثم بناء APK والتحقق من ملف الناتج وتوقيعه.

بعد نجاح سير العمل:
1. افتح تشغيل **Android CI** في GitHub Actions.
2. نزّل artifact الخاص بملف APK وثبّته للاختبار.
3. احتفظ بنسخة من ملف النسخ الاحتياطي قبل اختبار ترقية التطبيق على بيانات فعلية.

## ملاحظة حول مطابقة أسماء الاستيراد

تُطابق النسخة الحالية أسماء الأصناف بعد توحيد الأرقام وترتيب الكلمات ووحدة القياس. أما الأسماء التي تتضمن كلمات أو مواصفات إضافية مختلفة (مثل قطر أو قدرة) فقد تحتاج إلى قرار يدوي بين الدمج وإنشاء صنف جديد؛ لا ينبغي دمجها تلقائيًا لمجرد التشابه النصي.
