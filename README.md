# Buy Price Assistant GIMI — v1.1.0

تطبيق Flutter محلي لإدارة مرجع أسعار شراء الأصناف وبيعها، مع حفظ سجلات الأسعار على الجهاز ودعم العمل دون إنترنت.

## أهم ما أضيف في 1.1.0+3

- التبديل بين العربية والإنجليزية واتجاه الواجهة المناسب لكل لغة.
- حفظ اختيار المظهر: فاتح أو ليلي أسود أو حسب الجهاز.
- إعداد العملة الافتراضية للعمليات الجديدة إلى USD، مع دعم YER وSAR وUSD.
- حفظ العملة داخل كل سجل شراء أو بيع، وعدم تغيير عملة السجلات القديمة عند تغيير الإعداد الافتراضي.
- قائمة موحدة قابلة للتعديل للتصنيفات ووحدات القياس.
- اقتراح أسماء أصناف سابقة أثناء الكتابة؛ تظهر الأسماء النشطة والمؤرشفة، مع تحذير عند تطابق الاسم تمامًا.
- ترحيل قاعدة البيانات من v1 إلى v2 مع الاحتفاظ بالسجلات الموجودة وإسناد YER إلى السجلات القديمة.
- نسخ احتياطي يتضمن إعدادات التطبيق، مع الاستمرار في قبول النسخ القديمة `schemaVersion: 1`.
- اختبارات جديدة لترحيل قاعدة البيانات والعملات والاقتراحات والإعدادات.

## قرارات سلامة البيانات

لا يجري التطبيق تحويلًا تلقائيًا لأسعار الصرف. السعر يحتفظ بالعملة التي سُجل بها. ولا يُحسب فرق آخر سعر شراء عن آخر سعر بيع إذا كانت العملتان مختلفتين. عند ترحيل سجلات الإصدار السابق أو استعادة ملف احتياطي قديم، تُستخدم YER لأن الإصدار السابق لم يكن يحفظ رمز العملة.

## تشغيل الفحوص

```bash
python3 tooling/validate_update_package.py
python3 tooling/verify_update_sqlite.py
flutter pub get
dart format --output=none lib test
flutter analyze
flutter test --reporter expanded
python3 tool/prepare_android.py
flutter build apk --release
```

فُحصت هنا ملفات YAML، وبنية المصدر، وتعليمات إنشاء الجداول والترحيل والبحث فعليًا بواسطة SQLite عبر Python. **لم تُنفذ** أوامر Dart/Flutter أو بناء APK في بيئة التجهيز، لأن Flutter/Dart SDK غير متاحين فيها؛ لذلك لا يُعد هذا الملف ادعاءً بنجاح البناء أو جاهزية النشر.

## نطاق غير مشمول

لا يضيف هذا التحديث مزامنة سحابية أو تحويل أسعار صرف أو استيراد Excel/CSV أو نظام مستخدمين. لا تثبّت النسخة للاستخدام التجاري اليومي قبل نجاح CI واختبار APK يدويًا على الهاتف.
