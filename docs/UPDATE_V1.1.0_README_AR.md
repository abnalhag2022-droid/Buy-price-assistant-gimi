# حزمة تحديث Buy Price Assistant GIMI — الإصدار 1.1.0

## الغرض
هذه دفعة تطوير متكاملة مبنية على المصدر المحلي للإصدار 1.0.1+2. تُنتج شجرة مرشحة منفصلة، ولا تنفّذ `git add` أو `git commit` أو `git push` أو أي كتابة إلى GitHub.

## المحتويات الوظيفية
- تبديل واجهة التطبيق بين العربية والإنجليزية، مع اتجاه RTL/LTR الذي يحدده إعداد اللغة.
- حفظ تفضيل اللغة والمظهر والعملة الافتراضية محليًا.
- مظهر فاتح ومظهر ليلي أسود، مع ألوان قابلة للقراءة في الحالات الأساسية.
- إدارة تصنيفات الأصناف ووحدات القياس من شاشة الإعدادات.
- عرض اقتراحات أسماء من قاعدة البيانات المحلية أثناء كتابة اسم الصنف، بما فيها الأصناف المؤرشفة، مع إشعار عند وجود اسم مطابق.
- دعم YER وSAR وUSD وتسجيل العملة على كل عملية شراء أو بيع.
- ترحيل قاعدة البيانات من schema v1 إلى v2 دون حذف صفوف السجلات.
- نسخ الإعدادات مع نسخة البيانات، مع استمرار قبول ملفات النسخ القديمة schemaVersion 1 وتحويل العملة المفقودة إلى YER.
- إضافة اختبارات لاستعادة النسخ القديمة، والاقتراحات، والعملات، وترحيل قاعدة البيانات.

## إصدار البيانات
- التطبيق: `1.1.0+3`
- قاعدة البيانات: `2`
- تنسيق النسخة الاحتياطية: `schemaVersion: 2`
- العملة الافتراضية للعمليات الجديدة: USD
- عملة سجلات الإصدار السابق: YER عند ترحيل البيانات أو استعادة ملف قديم، لأن الإصدار السابق لم يكن يخزن رمز العملة.

لا تُجرى أي عملية تحويل سعر صرف تلقائية بين العملات. لا يُحسب الفرق بين آخر سعر شراء وآخر سعر بيع عندما تكون العملتان مختلفتين.

## خطوات التحقق المحلية
شغّل `python3 tooling/validate_update_package.py` لفحص ثوابت الإصدار والتكامل، ثم `python3 tooling/verify_update_sqlite.py` لتشغيل SQL الفعلي المستخرج من المصدر على SQLite، واختبار ترحيل v1 والبحث الجزئي وعمليات العملة. يكرر GitHub Actions الفحصين قبل Dart format والتحليل والاختبارات.

بيئة التأليف لا تحتوي على Flutter أو Dart SDK، ولذلك لا يُدّعى أن `dart format` أو `flutter analyze` أو `flutter test` أو إنشاء APK قد نجح محليًا. هذه خطوات إلزامية في GitHub Actions لاحقًا، ثم يتبعها اختبار يدوي على هاتف Android.

## تحديث المشروع الأساسي
شغّل `apply_update.py` على نسخة محلية نظيفة من الإصدار 1.0.1+2. يرفض البرنامج مصدرًا بإصدار أو schema مختلف، وينشئ مجلد مخرجات منفصلًا. الأصل لا يُعدّل. لا تنفذ أي خطوة Git إلا بعد مراجعة المخرجات والاتفاق على طريقة الرفع.
