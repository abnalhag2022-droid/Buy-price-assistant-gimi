# سجل التغييرات — 1.1.0+3

## إعدادات الاستخدام
- إضافة اختيار العربية أو الإنجليزية.
- إضافة المظهر الفاتح والليلي الأسود وخيار المظهر حسب الجهاز.
- إضافة العملة الافتراضية USD، مع خيارات SAR وYER.
- إضافة تحرير قوائم التصنيفات والوحدات وحفظها محليًا.

## الصنف والبحث
- البحث داخل الأسماء السابقة أثناء إدخال اسم جديد.
- ترتيب الاقتراحات لتظهر الأسماء المطابقة والأصناف النشطة قبل المؤرشفة.
- تحذير واضح من تكرار الاسم تمامًا، مع قرار المستخدم بالرجوع أو المتابعة.

## الأسعار والبيانات
- إضافة `currency_code` إلى سجل الشراء وسجل البيع.
- إضافة ترحيل آمن من قاعدة البيانات 1 إلى 2، مع القيمة الافتراضية YER للسجلات القديمة.
- عرض رمز العملة المسجل مع كل سعر وعدم إجراء مقارنة حسابية بين عملتين مختلفتين.
- تحديث تنسيق التاريخ حسب اللغة الحالية.

## النسخ الاحتياطي
- إدراج إعدادات اللغة والمظهر والعملة والتصنيفات والوحدات في ملف النسخ الاحتياطي الجديد.
- استمرار قبول `schemaVersion: 1`، واعتبار السجلات القديمة المسجلة بلا عملة YER.
- فحص الإعدادات الاحتياطية قبل تطبيق الاستعادة.
