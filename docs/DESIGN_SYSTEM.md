# نظام التصميم — Design system

الكود: `lib/ui/` (`tokens.dart`، `app_theme.dart`، `components/`). كل شاشة تستخدم هذه القيم والمكونات بدل الأرقام والألوان المتفرقة.

## الهوية

مأخوذة من أيقونة التطبيق (فاتورة بيضاء وعملة ذهبية على خلفية كحلية):

| الدور | اللون | الاستخدام |
|---|---|---|
| Navy (primary) | `#18365F` | العناوين البارزة، الأزرار الرئيسية، رأس القائمة |
| Gold (secondary) | `#F6C453` | زر «صنف جديد» العائم، علامة المفضلة في الوضع الداكن |

## الألوان الدلالية (`AppPalette`)

لكل معنى لون أساسي وحاوية ولون نص فوق الحاوية، في الوضعين الفاتح والداكن:

| المعنى | فاتح: أساسي / حاوية / نص | داكن: أساسي / حاوية / نص |
|---|---|---|
| شراء | `#1E5AA8` / `#E7F0FB` / `#0F3B73` | `#8DB7F0` / `#1A2E4A` / `#D6E6FA` |
| بيع | `#1B7A4C` / `#E4F4EA` / `#0D4B2E` | `#7FD3A6` / `#15382A` / `#CDEFDC` |
| تنبيه | — / `#FFF3D3` / `#5C4100` | — / `#3D3014` / `#FFE2A1` |
| خطأ | `#B3261E` / `#FDECEA` / `#7A1712` | `#FFB4AB` / `#4A1C1A` / `#FFDAD6` |
| معلومة | — / `#E8EEF7` / `#18365F` | — / `#1C2838` / `#D3E1F5` |

التباين (WCAG): كل أزواج النص ≥ 4.5:1 في الوضعين (أدناها 5.34:1 للنص الأخضر على الأبيض). نجمة المفضلة على الأبيض 3.73:1، وهي رمز لا نص، والحد للرموز 3:1. الحالة لا تُبلَّغ باللون وحده: كل بطاقة سعر تحمل أيقونة وتسمية («آخر شراء»/«آخر بيع»)، وكل تنبيه يحمل أيقونة.

## الخطوط والأرقام

- خط النظام (Roboto وNoto Arabic على Android) دون خطوط مضمّنة، للحفاظ على حجم التطبيق.
- العناوين بوزن 700، والنص بارتفاع سطر 1.45 ليناسب العربية.
- الأسعار بأرقام متساوية العرض (`tabularFigures`) لتصطف في القوائم.
- **سياسة الأرقام**: أرقام لاتينية في كل مكان (الشاشات والتصدير والاستيراد)، مع فاصل آلاف وحد أقصى خانتين عشريتين للسعر وثلاث للكمية (`formatMoney`، `formatQuantity`). الإدخال يقبل الأرقام العربية والفارسية والفاصلة العربية. التاريخ `dd/MM/yyyy`. الأرقام والأكواد داخل النص العربي معزولة باتجاه LTR (`ltrIsolate`) حتى لا يُقلب ترتيبها.
- عند التعديل تُعرض القيمة كما هي محفوظة دون فواصل (`editableNumber`).

## المكونات المشتركة

| المكوّن | الغرض |
|---|---|
| `PriceTile` | آخر سعر شراء أو بيع: المبلغ والعملة والتاريخ والمورد/العميل والكمية؛ «لا يوجد سعر مسجل» عند غياب السجل |
| `ProductCard` | الصنف في نتائج البحث: الاسم، شارات الكود والتصنيف والعلامة والوحدة، بطاقتا السعر، أزرار التسجيل أو إلغاء الأرشفة |
| `RecordButtons` | «تسجيل شراء» و«تسجيل بيع» بلوني الشراء والبيع |
| `SectionCard` / `SectionHeader` | تجميع محتوى الشاشة تحت عنوان |
| `NoticeBanner` | رسالة معلومة/تنبيه/خطأ/نجاح بأيقونة |
| `EmptyState` / `ErrorState` / `LoadingState` | الحالات الفارغة والأخطاء (رسالة مفهومة وزر إعادة) والتحميل |
| `showConfirmDialog` / `confirmDiscardChanges` | تأكيد الإجراءات، والإجراءات المدمرة بلون الخطأ |
| `AmountField` | إدخال الأسعار والكميات مع التحقق |
| `DebouncedSearchField` | بحث ينتظر توقف الكتابة |
| `ChoiceList` | اختيار واحد من قائمة عمودية (العملة) |
| `MetaChip` | شارة صغيرة لخاصية الصنف |
| `PageBody` | توسيط المحتوى وتحديد عرضه |

## الاتجاه واللغة

- العربية من اليمين لليسار والإنجليزية من اليسار لليمين عبر `Directionality` من `MaterialApp`؛ المسافات تستخدم `EdgeInsetsDirectional` حيث يهم الاتجاه.
- القائمة الجانبية تفتح من جهة البداية (يمين في العربية) وزرها في بداية شريط العنوان، حسب إرشادات Android. (كان 1.4.0 يفتحها من اليسار؛ انظر `docs/DECISIONS.md`.)
- كل نص ظاهر له صيغة عربية وإنجليزية، بما فيها رسائل قاعدة البيانات والاستيراد (`LocalizedMessage`).
